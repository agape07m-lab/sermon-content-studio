# 노안 설교연구실

이 폴더의 public/은 독립 PWA 정적 파일입니다. Cloudflare Workers assets로 배포합니다.

최신 예약 원고 읽기: ../noan-sermon-study/latest.json (공개 읽기 사본)

보안: 원고 보관함은 공개된 데이터만 연결해야 합니다. 앱의 수동 편집 원고는 사용자의 기기 localStorage에만 저장합니다.

배포: `npm install && npm run deploy` 또는 Cloudflare Build 연동 (root directory: noan-sermon-study).
